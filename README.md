# Welcome

I build open-source tools around **drones**, **photogrammetry**, **geomatics** and **cartography**.

Tools designed to be useful, free, and accessible.

### What you'll find here

- 🛩️ **Drone data processing** — acquisition, processing, analysis
- 🗺️ **Photogrammetry & cartography** — 3D reconstruction, orthophotos, DTM/DSM
- 📐 **Geomatics** — spatial data manipulation and exploitation
- 📦 **Datasets** — real production data, free to use

### Philosophy

The code is open. The documentation is there. The data is shared.
If you work in this field — professional, researcher, or advanced hobbyist — these tools are built for you.

### Support the project

This work is partly funded through **Patreon**. If you use these tools or want open solutions like these to keep existing and improving, your support matters.
