# Bienvenue

Je développe des outils open-source autour des **drones**, de la **photogrammétrie**, de la **géomatique** et de la **cartographie**.

Des outils conçus pour être utiles, gratuits et accessibles.

[🇬🇧 English](README.md) | 🇫🇷 **Français**

---

### Ce que vous trouverez ici

- 🛩️ **Traitement de données drone** — acquisition, traitement, analyse
- 🗺️ **Photogrammétrie & cartographie** — reconstruction 3D, orthophotos, MNT/MDS
- 📐 **Géomatique** — manipulation et exploitation de données spatiales
- 📦 **Jeux de données** — données réelles de production, libres d'utilisation

### Philosophie

Le code est ouvert. La documentation est là. Les données sont partagées.
Si vous travaillez dans ce domaine — professionnel, chercheur ou amateur avancé — ces outils sont faits pour vous.
